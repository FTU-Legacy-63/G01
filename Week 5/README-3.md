## **FEATURE SCOPE**

Hệ thống tính năng được thiết kế để phục vụ trực tiếp cho User Task, chia làm các nhóm cụ thể nhằm kiểm soát tiến độ code cho MVP.

### **2.1. Main Feature (Tính năng chính)**

* Data pop-up / Tabs: Hệ thống các cửa sổ hiển thị Báo cáo tài chính, Thông tin ngành và Tổng quan doanh nghiệp.  
* Q\&A: Khung hội thoại tương tác cho phép chọn câu hỏi và xem phản hồi từ Founder.  
* Decision Making Tabs: Widget Checklist (bắt Red flags qua lựa chọn Yes/No) và Thanh trượt phân bổ vốn (Slider)  
* Investment Report: Màn hình tổng kết hiển thị điểm Checklist, Tổng ROI, lãi/lỗ từng thương vụ và Feedback (điểm mạnh/yếu).

### **2.2. Supporting Feature (Tính năng hỗ trợ)**

* Dynamic Equity Calculator: Tự động tính toán và hiển thị % Equity nhận được theo thời gian thực khi người chơi kéo thanh trượt.  
* Fund Tracker: Thanh trạng thái ghim trên màn hình, liên tục hiển thị số dư ngân sách còn lại của quỹ.  
* Cơ chế UI Validation: Các ràng buộc trên giao diện như làm mờ thanh trượt khi chọn "Reject", vô hiệu hóa nút "Confirm" nếu chưa điền đủ Checklist.


### **2.3. Core Feature vs. Optional Feature**

* Core Feature (Bắt buộc hoàn thiện): Pitch, Industry, Company, Financials, Q\&A, Checklist, Invest/Reject, Capital Allocation slider, UI Validation và Investment Report.
