# **PITCH & LEDGER — GAME RULEBOOK**

## **1\. Game Objective**

You act as a **Venture Capitalist (VC)** managing a limited investment fund.

For each startup case, you must:

1. Review the available information about Industry, Business, Financial Statements and Q\&As with Founders.  
2. Conduct due diligence.  
3. Complete the **Yes/No checklist**.  
4. Choose **Invest** or **Reject**.  
5. If investing, decide **how much capital to allocate**.

Investment decisions are **not treated as objectively right or wrong**. Your performance is evaluated separately through **Checklist Accuracy** and **Investment Performance**.

## **2\. Due Diligence**

Review:

* **Founder Pitch**  
* **Industry Information**  
* **Company Information**  
* **Financial Statements**  
* **Founder Q\&A**

Use the information to identify business strengths, weaknesses, and financial red flags.

## **3\. Initial Capital**

* Each player starts the game with **1,000,000,000 VND**.
* This is the player's total available capital for investment throughout the game.
* After each round, the system automatically deducts the investment amount committed to the startup case when the player chooses **Invest**.
* If the player chooses **Reject**, no capital is deducted.
* The remaining capital is carried forward to the next round.
* The player cannot invest more than the **available capital**.

## **4\. Checklist**

* All checklist questions must be answered.  
* Each question accepts **Yes / No** only.  
* Answers are compared with the predefined benchmark.

### **Checklist Accuracy**

| Score | Interpretation |
| :---: | :---: |
| 85–100 | Excellent |
| 70–84 | Good |
| 50–69 | Moderate |
| \<50 | Weak |

## **5\. Investment Decision**

After completing the checklist, choose:

### **REJECT**

* Investment \= **0**  
* Equity \= **0%**  
* No investment return is generated.

### **INVEST**

* Select an investment amount using the slider.  
* The amount must satisfy the case's **minimum investment**, **maximum investable amount**, and **available capital**.  
* Each investment amount has a **predefined corresponding equity percentage**.  
* Equity terms **cannot be negotiated or changed**.

## **6\. Investment Return & Return Score**

Each startup has a **fixed simulated ROI**. Uninvested capital earns **0% return**.


| Portfolio Return | Return Score |
| :---: | :---: |
| ≥50% | 100 |
| 30–49% | 80 |
| 15–29% | 60 |
| 1–14% | 40 |
| 0 to −14% | 20 |
| \<−15% | 0 |

## **7\. Overall Performance**

| Overall Score | Classification |
| :---: | :---: |
| 85–100 | 🦈 Shark — Excellent |
| 70–84 | 🐟 Tuna — Strong |
| 50–69 | 🐠 Clownfish — Average |
| 30–49 | 🐡 Pufferfish — Weak |
| 0–29 | 🐟 Minnow — Poor |

## **8\. Final Report**

At the end, the game shows:

* Investment decisions  
* Total investment  
* Profit/Loss  
* Portfolio Return  
* Checklist Accuracy  
* Overall Performance  
* Classification  
* Feedback

> **Goal: Make evidence-based due diligence assessments and allocate limited capital effectively.**
